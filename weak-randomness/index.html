LAB 02

Weak Randomness

What it is

Weak randomness occurs when an application generates security-sensitive values using predictable algorithms. If password reset tokens follow a pattern, an attacker may be able to predict future tokens and bypass account verification.

Security Comparison

Security Property Vulnerable Fixed
Token generation Predictable sequence Web Crypto API
Token predictability Pattern can be identified No predictable sequence
Generator state Shared deterministic state Secure random generation
Token lifetime No expiration 2-minute expiration
Token reuse No one-time-use enforcement Consumed after verification
Candidate testing Up to 20 per simulation 5 shared verification attempts

Both implementations are browser-only educational simulations. Production authentication requires server-side token storage and verification.

Fix snapshot

Replace predictable token generation with a cryptographically secure random number generator.

Security Considerations

Secure randomness prevents sequence-based token prediction, but it is only one part of a secure password reset system. Real applications must enforce token expiration, one-time use, rate limiting, and verification on the server.
